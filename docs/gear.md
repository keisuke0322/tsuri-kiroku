# 所有道具・基本セット・使用履歴

「道具」画面で所有道具・基本セット・お気に入りを本人限定で管理します。
道具は種類・名前を必須とし、メーカー・型番・スペック・管理用メモは任意です。
管理用メモは釣果の使用内容には含めません。画像は扱いません。

- 所有道具は1000点、基本セットは100組（使用終了・登録解除を含む）。
- 1件の釣果は20組、1組・1セットは30点まで。同じ道具の複数セットでの共用に対応します。
- 道具名・セット名・メーカー・型番は120文字、スペックは300文字、管理用メモは2000文字。
- 対象魚種は80文字、組み合わせ・セットの釣り方は200文字。
- 使用履歴は50件単位で読み込みます。

## 記録

最初は1組を表示します。基本セットの一括選択、個別選択、検索、追加・取り外し、
複製に対応します。ロッドなどの差し替えは古い道具を取り外して新しい道具を選びます。
ルアー・仕掛けも複数選択できます。道具・セットの候補はお気に入りを優先します。
記録中の道具追加は所有道具への保存が標準です。「今回の記録だけ」は所有道具へ保存しません。
従来の「釣り方・仕掛け」の自由入力と魚種別の匹数・サイズはそのまま使えます。

1魚種の入力では自動で紐づけ、チェックを外して解除できます。
魚種名の編集は紐づけへ反映し、削除した魚種は紐づけから外します。
履歴からコピーした場合も、今回の魚種に合わせて紐づけを確認してください。

道具・基本セットを編集しても、既存の釣果の使用内容は変わりません。
使用時点の名前・メーカー・型番・スペック・セット名・釣り方・魚種を保存しています。
記録した内容の修正はその釣果を編集します。道具の管理用メモ・お気に入りは記録へ複製しません。

## 履歴・再利用

道具・セットの「使用履歴」から絞り込めます。魚種の検索は組み合わせへ明示的に
紐づけた魚種の完全一致です。魚種を紐づけていない履歴は魚種指定なしで確認できます。
「当日の道具が同じ記録」は、その履歴と道具・釣り方が同じ記録を検索します。

- 道具の順序・紐づけた魚種・基本セットIDは同一性に含めません。
- 所有道具はIDで判定します。名前・スペックの変更後も同じ道具です。
- 今回だけ入力した道具は種類・名前・メーカー・型番・スペックが同じ場合に一致します。
- 釣り方は前後の空白を除いて完全一致で判定します。
- 履歴は「その組み合わせを使用した記録」です。記録全体の匹数・サイズを
  その組み合わせだけの釣果として表示・集計しません。

履歴は今回の記録へコピーでき、名前を付けて基本セットへも保存できます。
コピー元とコピー先は独立しています。使用終了の道具・登録解除したセットも
履歴に残り、コピーできます。再利用時には状態を表示し、差し替え・取り外しを促します。
通常の候補は使用中だけを表示し、既に選んだ使用終了の道具は勝手に外しません。

## ナビゲーション・入力保持

スマートフォンは下部固定、PCはヘッダー下に「釣り記録・道具・マイページ」を表示します。
道具画面内は所有道具・基本セット・使用履歴を切り替えます。プロフィール編集・
ログアウト・本人の写真保存容量はマイページにあります。

セクションを保持したまま表示を切り替え、検索条件・スクロール位置・入力中の内容を
メモリ上に保持します。釣果入力から「道具画面へ（入力を保持）」を使って移動し、
「釣り記録」で入力へ戻れます。ブラウザーの再読み込み・終了をまたぐ下書き保存はしません。

## 保存・権限・移行

`0010_gear.sql` は `gear`・`gear_sets`・`catch_combinations` の追加のみです。
既存の釣果・写真・位置情報は変更せず、自由入力から道具を自動生成しません。
組み合わせ未指定の旧クライアントによる編集でも既存の使用内容を保持し、
削除された魚種との紐づけだけを除去します。

管理APIと履歴APIはログインした本人のデータだけを取得し、更新対象と選択IDの
所有者をサーバーで検証します。釣果上の使用内容は既存の釣果の閲覧権限に従います。
写真の保存容量は本人分だけを返し、他のユーザーの容量は公開しません。

変更を戻す場合は前のWorkerへ戻します。追加テーブルは残せるので、既存釣果を
削除する逆マイグレーションは不要です。stagingの検証後に同じSQLをproductionへ適用します。
